# Debug HUD (F3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F3 toggles a corner panel with fps, 1% low, a frame-time graph, a per-frame time breakdown, CPU and GPU usage, the active GPU, and the last frame drop with its likely cause; drops are also logged.

**Architecture:** `rt/perf` keeps per-frame records fed from the existing frame boundary (`DGXGraphics::waitRetrace` hook in `enhance/framerate.cpp`) and classifies drops using the recent-events ring (`rt/trace`). `rt/sysinfo` samples CPU (procfs) and GPU (Dawn adapter info, NVML via dlopen, AMD sysfs) at 2 Hz. `ui/debug_hud` draws the panel with ImGui on the overlay infrastructure.

**Tech Stack:** C++20 runtime, aurora (ImGui, Dawn `wgpu::Adapter`), procfs/sysfs, NVML (optional, runtime-loaded).

**Spec:** `docs/superpowers/specs/2026-11-23-debug-hud-design.md`

**Prerequisite:** `docs/superpowers/plans/2026-11-23-exit-and-settings.md` Tasks 4–5 (overlay input layer, `ui::frame()` hook in `gfx.cpp`, `rt::save_config_value`).

## Global Constraints

- F3 works everywhere; state saved as `debug_hud = true|false` in `config.toml`.
- Drop = frame time > 2× target frame time (target = `1 / enh::effective_fps()`).
- Graph and 1% low cover the last 4 s; fps / ms averaged over 0.5 s.
- No guest-clock reads (they advance `--fast` virtual time); host `steady_clock` only. Nothing in `--headless`.
- NVML is optional: `dlopen("libnvidia-ml.so.1")`, no build dependency.

## Review Focus

1. **Laptop running on the Radeon while NVML exists** (driver installed, other GPU active): GPU busy must come from the adapter actually in use, matched by PCI vendor (0x10de NVIDIA, 0x1002 AMD) and name, never NVML device 0 blindly. Test: Task 2 `pick_gpu_source`.
2. **Loading screens / long stalls** (a 2 s DVD load): one drop logged, not hundreds; graph scale clamps (cap at 100 ms). Test: Task 1 `long_stall_one_drop`.
3. **Real-time vs `--fast`**: perf stats never read the guest clock. Test: Task 1 asserts `--fast` output identical with HUD stats enabled (existing determinism checks: record-input round trip stays equal).
4. **No `/proc/self/task/<tid>`** (permissions, containers): CPU shows "n/a", no crash. Test: Task 2 `cpu_parse_missing`.
5. **F3 while the overlay is open** and **in `--offscreen`**: toggles, saved, drawn; never consumes game input. Test: Task 3 `test_hud_toggle_saved`.

### Task 1: Frame records and drop detection (`rt/perf`)

**Files:** Create `runtime/rt/perf.hpp`, `runtime/rt/perf.cpp`; Modify `runtime/enhance/framerate.cpp` (call `perf_frame` from the `waitRetrace` hook); Test `tests/runtime/test_perf.cpp`.

**Interfaces (namespace `rt`):**
- `struct FrameRecord { double total_ms, game_ms, present_ms, pace_ms; uint32_t retrace; };`
- `struct Drop { double ms; uint32_t retrace; std::string cause; };`
- `void perf_frame(double now_s, double present_s, double pace_s, double target_s);` — one call per game frame; `game_ms = total - present - pace`.
- `const std::deque<FrameRecord>& perf_history();` (last 4 s by `now_s`), `double perf_fps()`, `double perf_ms()` (0.5 s window), `double perf_one_percent_low()` (fps of the slowest 1% over 4 s), `std::optional<Drop> perf_last_drop()`.
- Drop cause: scan ring entries with `seq` after the previous frame's `g_trace_seq`; prefer the largest `Dvd` read (`"dvd read <path or offset> (<size>)"`), else the last `Scene`, else `"thread switch"` if any, else `""`. A run of consecutive drop frames counts as one drop (logged once, with the longest frame).
- Logging: `[perf] drop 38.1 ms at retrace N: <cause>` (stderr + run log).

- [ ] **Step 1: Failing tests** (`test_perf.cpp`): `fps_and_low` (feed 240 frames at 1/240 s with 3 frames of 20 ms → fps ≈ 240 within 5, 1% low < 60); `drop_cause_dvd` (`trace(Ev::Dvd,"read",0,2'000'000,"dataDir/x.arc")` then a 40 ms frame → `cause` contains `dvd read dataDir/x.arc` and `2.0 MB`); `long_stall_one_drop` (five consecutive 400 ms frames → one `Drop`, `ms == 400`); `history_window` (frames older than 4 s are evicted).
- [ ] **Step 2:** FAIL. **Step 3:** implement; wire `perf_frame` in `hle_waitRetrace__11DGXGraphicsFv` using the existing `t0/t1/host_now()` values. **Step 4:** PASS; full suite (`--fast` determinism tests unchanged).

### Task 2: CPU and GPU sampling (`rt/sysinfo`)

**Files:** Create `runtime/rt/sysinfo.hpp`, `runtime/rt/sysinfo.cpp`; Modify `runtime/rt/gfx.cpp` (expose adapter info); Test `tests/runtime/test_sysinfo.cpp`.

**Interfaces (namespace `rt`):**
- `struct GpuInfo { std::string name, backend; uint32_t vendor = 0, device = 0; };` `GpuInfo gfx_adapter_info();` in `gfx.cpp` via `webgpu::g_adapter.GetInfo()` (header `webgpu/gpu.hpp`, already reachable through the private aurora include dir); also logged once to the run log at init.
- `double cpu_ticks_from_stat(const std::string& stat_line);` — utime+stime (fields 14–15, after the `)` of the comm field); returns -1 on parse failure.
- `enum class GpuSource { None, Nvml, AmdSysfs };` `GpuSource pick_gpu_source(uint32_t vendor, bool nvml_available, bool amd_sysfs_available);` — 0x10de + NVML → Nvml; 0x1002 + sysfs → AmdSysfs; else None.
- `struct SysSample { double cpu_pct = -1, game_thread_pct = -1, gpu_busy_pct = -1; };` `void sysinfo_init(pid_t game_tid, const GpuInfo&);` `const SysSample& sysinfo_sample(double now_s);` (re-samples at most every 0.5 s). NVML: `dlopen`, `nvmlInit_v2`, iterate devices, pick the one whose name matches `GpuInfo::name` (case-insensitive substring), `nvmlDeviceGetUtilizationRates().gpu`. AMD: `/sys/class/drm/card*/device/{vendor,device,gpu_busy_percent}` matching the adapter's IDs.

- [ ] **Step 2:** FAIL. **Step 3:** implement. **Step 4:** PASS; full suite.
- [ ] **Step 5: Human check:** real window: the logged adapter is the RTX 5070 (or note which one Dawn picked); busy % moves with load.
